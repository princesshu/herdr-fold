# herdr-fold for the Herdr app

herdr-fold's mod for the Herdr desktop app: Spaces and Conversations on the left, Files, Search, Changes and Issues on
the right, the preview tab, and a conversation with Claude as a chat. herdr-fold's installer puts it in the app; see
[herdr-fold](https://github.com/princesshu/herdr-fold).

herdr-fold.
